Phase 02 · SQL Analysis

The Query That Found
The Stockout Pattern.

Q3 stockout tiering — categorizing inventory failure by severity and store.

-- Q3: Stockout Severity Tiering by Store & Category
-- Identifies systemic failure vs. isolated incident

WITH stockout_base AS (
  SELECT
    store_id,
    category,
    product_id,
    inventory_qty,
    reorder_point,
    CASE
      WHEN inventory_qty = 0
        THEN 'IMMEDIATE_STOCKOUT'
      WHEN inventory_qty <= reorder_point
        THEN 'CRITICAL_LOW'
      WHEN inventory_qty <= reorder_point * 1.5
        THEN 'WARNING'
      ELSE 'ADEQUATE'
    END AS stockout_tier
  FROM inventory_fact
  WHERE snapshot_date = CURRENT_DATE
),

store_summary AS (
  SELECT
    store_id,
    category,
    COUNT(*) AS total_skus,
    SUM(CASE WHEN stockout_tier = 'IMMEDIATE_STOCKOUT'
      THEN 1 ELSE 0 END) AS immediate_out,
    ROUND(
      100.0 * SUM(CASE WHEN stockout_tier != 'ADEQUATE'
        THEN 1 ELSE 0 END) / COUNT(*), 1
    ) AS pct_at_risk
  FROM stockout_base
  GROUP BY store_id, category
)

SELECT *
FROM store_summary
WHERE immediate_out > 0
ORDER BY immediate_out DESC, pct_at_risk DESC;

What This Revealed

The tiering logic separated process failure from data failure — 18 products were at zero inventory with no reorder trigger ever set.

Key Finding

No store had reorder automation. The stockouts weren't a system bug — they were a management process that never existed.

Phase 03 · Python Analysis

Return Rate Heatmap.
One Number Stood Out.

Category × Store return rate matrix. Atlanta Buckhead Home & Kitchen: 63%.

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# Load cleaned transaction data
df = pd.read_csv('pinnacle_cleaned.csv')

# Calculate return rate: returns / total transactions
return_df = (
    df.groupby(['store_name', 'category'])
    .agg(
        total=('transaction_id', 'count'),
        returns=('is_return', 'sum')
    )
    .assign(rate=lambda x: x.returns / x.total)
    .reset_index()
)

# Pivot for heatmap format
pivot = return_df.pivot(
    index='category',
    columns='store_name',
    values='rate'
)

# Plot
fig, ax = plt.subplots(figsize=(12, 6))
sns.heatmap(
    pivot,
    annot=True, fmt='.0%',
    cmap='Reds', linewidths=0.5,
    ax=ax
)
ax.set_title('Return Rate by Category & Store')
plt.tight_layout()
plt.savefig('return_heatmap.png', dpi=150)
